# دفتر مالی — راهنمای راه‌اندازی

## پیش‌نیاز
- هاست PHP نسخه ۸.۰ به بالا
- دیتابیس MySQL/MariaDB

## مراحل نصب

۱. تمام فایل‌ها را روی هاست آپلود کنید (ساختار پوشه‌ها را همان‌طور که هست نگه دارید).

۲. دیتابیس بسازید و فایل `schema.sql` را داخلش ایمپورت کنید.

۳. فایل `config/config.example.php` را کپی کرده و با نام `config/config.php` ذخیره کنید. سپس مقادیر `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` را با اطلاعات دیتابیس خودتان جایگزین کنید.
   - اگر پروژه را داخل یک زیرپوشه نصب کرده‌اید (نه ریشه دامنه)، مقدار `APP_BASE_PATH` را هم پر کنید (مثال داخل فایل هست).
   - مقدار `APP_SECRET_KEY` را هم به یک رشته تصادفی دلخواه تغییر دهید.

۴. آدرس سایت را باز کنید؛ چون هنوز کاربری ساخته نشده، مستقیم به `setup.php` منتقل می‌شوید تا حساب مدیر اصلی را بسازید.

۵. بعد از ساخت حساب مدیر، از صفحه ورود وارد شوید.

## ساختار پوشه‌ها
```
config/     تنظیمات دیتابیس
includes/   کلاس‌ها و قالب‌های مشترک (auth, csrf, db, functions, header, sidebar, footer)
admin/      مدیریت کاربران و دسته‌بندی‌ها (فقط مدیر)
api/        اندپوینت‌های AJAX (ثبت/حذف تراکنش)
assets/     CSS و JS
```

## چیزهایی که در نسخه اول کامل/اصلاح شد
- **`admin/users.php`** و **`admin/categories.php`** ساخته شدند — در فایل قبلی فقط لینکشان در منو و استایل‌شان در CSS بود ولی خودشان وجود نداشتند.
- باگ مسیر رفع شد: لینک‌های منو و آدرس CSS/JS با ثابت `APP_BASE_PATH` درست کار می‌کنند (حتی از داخل `admin/`).
- نمودار صفحه گزارش تکمیل شد.
- `.gitignore` اضافه شد.

## نکات امنیتی مدیریت کاربران
- حداقل همیشه یک مدیر فعال باید در سیستم بماند.
- کاربری که تراکنش ثبت کرده باشد قابل حذف نیست؛ به‌جایش غیرفعالش کنید.

## به‌روزرسانی بزرگ دوم — چندکاربره واقعی + موبایل‌فرست

**جداسازی کامل کاربران:**
- هر کاربر (از جمله ادمین) فقط تراکنش‌ها، داشبورد و گزارش‌های خودش را می‌بیند و فقط می‌تواند تراکنش خودش را ویرایش/حذف کند — این کنترل هم در UI و هم در تمام APIها (`add_transaction.php`, `update_transaction.php`, `delete_transaction.php`) و با شرط `WHERE user_id = ...` در تمام کوئری‌ها اعمال شده، نه فقط ظاهر صفحه.
- دسته‌بندی‌ها (`categories`) مشترک بین همه کاربران باقی مانده‌اند (تغییری در این بخش داده نشد).
- صفحه جدید **`admin/all-transactions.php`** (مدیریت → «تراکنش همه کاربران»): فقط مدیر می‌بیند، تراکنش تمام کاربران (ادمین و عادی) را نشان می‌دهد ولی **فقط مشاهده** است — دکمه ویرایش/حذف ندارد.

**صفحات جدید/تغییریافته:**
- `index.php`: فقط ثبت سریع تراکنش + آخرین تراکنش‌های خودم (با دکمه ویرایش/حذف).
- `dashboard.php` (جدید): آمار امروز/هفته/ماه/سال + نمودار روند ماهانه (۱۲ ماه اخیر شمسی) و سالانه — فقط داده‌های خود کاربر.
- `transactions.php`: لیست کامل تراکنش‌های خودم با فیلتر (شامل «بازه دلخواه» که قبلاً در کد بود ولی راه دسترسی نداشت) + ویرایش.
- `api/update_transaction.php` (جدید): ویرایش تراکنش، فقط مالک اجازه دارد.

**تاریخ شمسی واقعی:**
- همه‌جا (فرم ثبت، ویرایش، فیلتر بازه، گزارش) به‌جای `<input type="date">` مرورگر (که میلادی نشان می‌دهد)، یک تقویم شمسی سفارشی (`assets/js/jalali-datepicker.js`) اضافه شد — بدون وابستگی به کتابخانه خارجی، الگوریتمش دقیقاً منطبق با همان تابع تبدیل PHP پروژه است.

**موبایل‌فرست:**
- سایز فونت ورودی‌ها روی موبایل به ۱۶px رسید (جلوگیری از زوم خودکار iOS)، دکمه‌ها و آیتم‌های منو برای لمس بزرگ‌تر شدند. نمای کارتی جدول‌ها روی موبایل از قبل وجود داشت، فقط تیون شد.
